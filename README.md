## Описание проекта

Программа показывает плавное циклическое превращение круга в равносторонний
треугольник и обратно. Фигура строится в полярных координатах и отображается
в окне Tkinter. Учебная работа относится к теме «Сложная анимация».

## Функциональные возможности

### Основной функционал

- Построение фигуры по 180 точкам в полярных координатах.
- Плавное превращение окружности в треугольник и обратно.
- Автоматическая смена направления на границах превращения.
- Обновление холста с запланированным интервалом 20 мс.

### Дополнительный функционал

- Пауза и продолжение с помощью кнопки или пробела.
- Сброс к исходной окружности с помощью кнопки или клавиши R.
- Тесты геометрии и состояния анимации без открытия окна.

## Требования к системе

- Python 3.9 или выше с поддержкой Tkinter и Tcl/Tk.
- Windows, macOS или Linux с графическим окружением.
- Стандартные библиотеки: `math`, `tkinter`; для тестов — `unittest`.
- Сторонние зависимости отсутствуют. Это указано в `requirements.txt`.

## Установка и запуск

### 1. Получение проекта

На странице репозитория GitHub выберите **Code → Download ZIP** и распакуйте
архив. Либо скопируйте HTTPS-адрес из меню **Code** и выполните:

```bash
git clone <HTTPS-адрес-репозитория> hard-anim
cd hard-anim
```

Вместо выражения в угловых скобках подставьте адрес этого репозитория.

### 2. Создание и активация виртуального окружения

По требованиям преподавателя `venv/` не исключается в `.gitignore` и включается
в репозиторий. Окружение зависит от компьютера, поэтому после скачивания
пересоздайте его. Параметр `--clear` очищает только содержимое папки `venv`.

**Windows, командная строка cmd:**

```bat
python -m venv --clear --without-pip venv
venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv --clear --without-pip venv
source venv/bin/activate
```

Окружение создаётся без pip, поскольку внешние библиотеки не используются.
Устанавливать пакеты из `requirements.txt` не требуется.

### 3. Проверка Tkinter

В активированном окружении выполните:

```bash
python -m tkinter
```

Должно открыться тестовое окно. Если Tkinter отсутствует, установите его
для выбранной версии Python. Для системного Python Ubuntu обычно используется
команда `sudo apt install python3-tk`.

### 4. Запуск программы

```bash
python main.py
```

### 5. Управление

| Действие | Кнопка или клавиша |
| --- | --- |
| Пауза / продолжение | «Пауза» / «Продолжить» или пробел |
| Вернуть круг и остановить движение | «Сброс» или R в английской раскладке |
| Выход | Закрытие окна |

## Математика преобразования

Для каждой точки выбирается угол `a` от 0 до 2π. Радиус окружности `R = 200`.
Направление луча сводится к сектору одной стороны треугольника. Радиус
вписанной окружности равен `R / 2`, поэтому расстояние до стороны:
`r_triangle = (R / 2) / cos(delta)`.

Промежуточная фигура рассчитывается линейной интерполяцией:

```text
r = R * (1 - t) + r_triangle * t
x = center_x + r * cos(a)
y = center_y - r * sin(a)
```

При `t = 0` получается окружность, при `t = 1` — треугольник. Минус в формуле
для `y` учитывает направление вертикальной оси холста. Прогресс изменяется
на 0.01 за кадр. Полный цикл занимает примерно 4 секунды; реальное время
зависит от обработки событий Tkinter.

## Пример использования

1. Активируйте окружение и выполните `python main.py`.
2. Наблюдайте переход от круга к треугольнику и обратно.
3. Нажмите пробел, чтобы рассмотреть промежуточную фигуру.
4. Нажмите R: появится исходный круг, программа останется на паузе.
5. Нажмите «Продолжить», чтобы возобновить движение.

## Проверка программы

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют постоянный радиус окружности, вершины и середины сторон
треугольника, смену направления, границы прогресса и сброс.
